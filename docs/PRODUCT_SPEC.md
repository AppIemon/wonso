# wonso — 원소·원자·분자 모드 제품 기획서

> **범위**: 수소(H, Z=1) ~ 오가네손(Og, Z=118) 전 원소
> **모드**: 원소 / 원자 / 분자 (3대 학습 모드)
> **형태**: 클라이언트 + 서버사이드 풀스택
> **상태**: 기획 단계 (코드 미구현)

---

## 1. 한 줄 정의

**wonso**는 주기율표 전체(118원소)를 **원소·원자·분자** 세 관점으로 탐색·학습·퀴즈할 수 있는 화학 교육 앱이다. 클라이언트는 즉각적인 시각화와 오프라인 학습을, 서버는 진도·퀴즈·콘텐츠 배포를 담당한다.

---

## 2. 문제 정의 & 목표

### 2.1 학습자가 겪는 문제

| 문제 | 설명 |
|------|------|
| **원소 ≠ 원자 ≠ 분자 혼동** | "수소 원소"와 "수소 분자(H₂)"를 같은 것으로 인식 |
| **계수·아래첨자 혼동** | 2H₂O에서 2, H, O 숫자의 의미를 구분 못함 |
| **주기율표 = 암기표** | 원소를 위치·성질·구조와 연결하지 못함 |
| **시각화 부재** | 전자 배치·결합을 눈으로 확인할 기회가 적음 |

### 2.2 제품 목표

1. **118원소 전수 커버** — 누락 없이 H~Og
2. **3모드 일관 UX** — 같은 원소를 원소/원자/분자 관점에서 전환
3. **한국 교육과정 정합** — 중등 화학(원소·원자·분자) 단원과 연계
4. **오프라인 우선** — 기본 학습은 클라이언트 캐시로 동작
5. **서버 확장** — 진도·퀴즈·리더보드·콘텐츠 업데이트

### 2.3 비목표 (v1에서 하지 않음)

- 유기화학 전체(반응 메커니즘, 합성 경로)
- 3D 분자 오비탈 정밀 시뮬레이션
- 실험실 안전·실험 절차 시뮬레이션
- Markush 구조(특허 마크) 편집기

## 3. 용어 정의 (핵심)

| 용어 | 정의 | UI에서의 표현 |
|------|------|---------------|
| **원소(Element)** | 같은 종류의 원자를 통칭. 주기율표 한 칸 | 원소 모드 카드, 기호+한글명 |
| **원자(Atom)** | 원소의 개별 입자. 양성자·중성자·전자 수로 구분 | Bohr/쉘 모델, 동위원소 |
| **분자(Molecule)** | 2개 이상 원자의 결합체 | 분자식·구조식·계수/아래첨자 |
| **동위원소** | 같은 원소, 다른 중성자 수 | 원자 모드 서브뷰 |
| **이온** | 전자를 잃거나 얻은 원자/원자团 | 원자 모드 확장 (v1.1) |
| **계수** | 분자 앞 전체 개수 (2H₂O의 2) | 분자 모드 하이라이트 |
| **아래첨자** | 원자 개수 (H₂O의 2) | 분자 모드 하이라이트 |

## 4. 3대 모드 상세 기획

### 4.1 원소 모드 (Element Mode)

**목적**: 주기율표를 "지도"로 쓰며 원소의 위치·성질·분류를 학습

#### 4.1.1 핵심 화면

1. **주기율표 메인** — 118칸, 카테고리 색상, 반응형(모바일: 스크롤+줌)
2. **원소 상세 카드** — 기본 정보 + "원자 모드로 보기" / "관련 분자 보기" CTA
3. **검색·필터** — 한글명/영문명/기호, 카테고리, 상태(상온), 기간·족
4. **비교 뷰** — 2~4개 원소 속성 나란히 (전기음성도, 원자량 등)

#### 4.1.2 원소 상세 데이터 필드 (118개 전수)

| 필드 | 필수 | 비고 |
|------|------|------|
| 원자번호 (Z) | ✅ | 1~118 |
| 기호 (symbol) | ✅ | IUPAC |
| 한글명 | ✅ | 대한화학회 표기 |
| 영문명 | ✅ | |
| 원자량 | ✅ | 불확정 시 범위 표기 |
| 족·주기 | ✅ | |
| 카테고리 | ✅ | 알칼리금속, 할로겐, 전이금속 등 |
| 상온 상태 | ✅ | 고체/액체/기체 |
| 전자 배치 | ✅ | 축약형 |
| 전기음성도 | ⚪ | 없는 원소는 "—" |
| 밀도 | ⚪ | |
| 발견 연도 | ⚪ | |
| displayRow / displayColumn | ✅ | 주기율표 레이아웃 |
| aliasesKo | ⚪ | 검색용 별칭 |

#### 4.1.3 학습 활동

- **탐색**: 원소 클릭 → 상세 카드
- **퀴즈**: "이 기호는?" / "이 족은?" / "상온 기체는?"
- **챌린지**: 10문제 연속, 오답 즉시 해설

---

### 4.2 원자 모드 (Atom Mode)

**목적**: "원소의 한 입자"를 구조적으로 이해 — 양성자·중성자·전자

#### 4.2.1 핵심 화면

1. **원자 구조 뷰어** — 핵(양성자+중성자) + 전자 쉘
2. **구성 요소 패널** — p⁺, n⁰, e⁻ 슬라이더/입력 (교육용)
3. **동위원소 탭** — 같은 Z, 다른 질량수
4. **이온 탭 (v1.1)** — Na⁺, Cl⁻ 등

#### 4.2.2 시각화 레벨 (학년별 토글)

| 레벨 | 대상 | 표현 |
|------|------|------|
| L1 (중1~2) | Bohr 모델 | K,L,M 쉘 원형, 최대 8개 규칙 강조 |
| L2 (중3) | 쉘+아래첨자 | 2-8-8 규칙, 원자가 전자 하이라이트 |
| L3 (고등) | 오비탈 개요 | s/p/d 개념 소개 (텍스트+간단 도식) |

#### 4.2.3 원자 데이터 (118원소 × 기본 구성)

| 필드 | 설명 |
|------|------|
| defaultProtons | = Z |
| defaultNeutrons | 가장 흔한 동위원소 |
| defaultElectrons | = Z (중성 원자) |
| shellDistribution | [2,8,8,…] |
| valenceElectrons | 원자가 전자 수 |
| commonIsotopes | [{massNumber, abundance, neutrons}] |
| ionForms | [{charge, electronCount}] (v1.1) |

#### 4.2.4 학습 활동

- **빌드**: "양성자 6개, 전자 6개 → 무슨 원소?" (탄소)
- **동위원소 퀴즈**: "¹²C와 ¹⁴C의 차이는?"
- **전자 배치 쓰기**: 2-8-1 → 나트륨

---

### 4.3 분자 모드 (Molecule Mode)

**목적**: 원자가 모여 만든 "결합체"를 분자식·구조로 이해

#### 4.3.1 핵심 화면

1. **분자 라이브러리** — 원소별·카테고리별 (물, 이산화탄소, 암모니아…)
2. **분자식 파서/뷰어** — 계수·아래첨자 색상 분리
3. **원자 구성 분해** — H₂O → H×2 + O×1 시각화
4. **방정식 모드 (v1.2)** — 2H₂ + O₂ → 2H₂O

#### 4.3.2 분자 데이터 스키마

```text
Molecule {
  id: string
  nameKo: string
  nameEn: string
  formula: string          // "H2O", "CO2"
  formulaDisplay: string   // "H₂O", "CO₂" (유니코드 아래첨자)
  elements: [{symbol, count}]
  category: enum           // inorganic, organic_simple, ionic...
  relatedElementZ: number[] // 연결 원소 (원소 모드 역참조)
  structureType: enum      // linear, bent, tetrahedral...
  descriptionKo: string    // 1~3문장 해설
  difficulty: 1|2|3
}
```

#### 4.3.3 v1 분자 커버리지 목표

| 티어 | 개수 | 예시 |
|------|------|------|
| **필수 (Tier A)** | ~50 | H₂O, CO₂, O₂, N₂, H₂, NaCl, HCl, NH₃, CH₄, C₂H₆O |
| **확장 (Tier B)** | ~150 | 주요 무기·단순 유기 |
| **전체 (Tier C)** | ~500+ | 원소별 관련 분자 전수 |

118원소 각각 **최소 1개** 관련 분자 연결 (Og 등은 "알려진 분자 없음" 명시)

#### 4.3.4 학습 활동

- **파싱 퀴즈**: "2H₂O에서 산소 원자 몇 개?"
- **조립**: 주어진 원자로 분자 만들기 (드래그)
- **구분 퀴즈**: "원소 / 원자 / 분자" 3지선다

## 5. 모드 간 연결 (Cross-Mode Navigation)

```
주기율표 [원소 모드]
    │ 클릭: 수소(H)
    ├─→ 원소 상세 (성질·위치)
    │       ├─→ [원자 모드] 수소 원자 ¹H 구조
    │       └─→ [분자 모드] H₂, H₂O 관련 분자
    │
퀴즈 허브
    ├─ 원소 퀴즈
    ├─ 원자 퀴즈
    └─ 분자 퀴즈
```

**공통 컨텍스트 바**: 현재 선택 원소(Z, 기호, 한글명)가 3모드에서 유지

## 6. 사용자 시나리오

### 6.1 중학생 (자기주도)

1. 앱 열기 → 원소 모드 주기율표
2. "산소" 검색 → O 상세 카드
3. "원자로 보기" → 8개 전자 쉘 확인
4. "분자로 보기" → O₂, H₂O, CO₂ 탐색
5. 분자 퀴즈 5문제 → 오답 해설 읽기

### 6.2 교사 (수업 자료)

1. 서버 대시보드에서 "원자·분자 구분" 퀴즈 세트 생성
2. 학급 코드 공유 → 학생 진도 확인
3. 특정 원소(예: 탄소) 3모드 링크를 수업 슬라이드에 embed

### 6.3 부모 (진도 확인)

1. 자녀 계정 연결
2. 주간 학습 리포트 (퀴즈 정답률, 탐색 원소 수)

## 7. 퀴즈·게임화

### 7.1 퀴즈 유형 매트릭스

| 모드 | 유형 | 예시 |
|------|------|------|
| 원소 | 기호↔이름 | "Na" → 나트륨 |
| 원소 | 위치 | "할로겐은 몇 족?" |
| 원소 | 성질 | "상온 액체 원소?" (Hg, Br) |
| 원자 | 구성 | "탄소 원자의 전자 수?" |
| 원자 | 동위원소 | "중성자 8개인 탄소?" |
| 분자 | 파싱 | "CO₂의 원자 총수?" |
| 분자 | 구분 | "O₂는 원소/원자/분자?" → 분자 |
| 통합 | 3지선다 | "다음 중 원자만?" |

### 7.2 난이도 & XP

- **Easy**: 1~20번 원소, Tier A 분자
- **Medium**: 1~56번, Tier B
- **Hard**: 전체 118, Tier C, 동위원소·이온
- **XP**: 탐색 +5, 퀴즈 정답 +10, 연속 정답 보너스
