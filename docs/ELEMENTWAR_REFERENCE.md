# elementwar.xyz — 레퍼런스 분석 & 모드 이식 맵

> **URL**: https://elementwar.xyz
> **게임명**: 원소 대전 (Element War)
> **역할**: Minecraft Fabric 모드의 게임플레이·UI·시스템 레퍼런스

---

## 1. 사이트 핵심 정의

**원소 대전**은 화학 원소·분자를 소재로 한 **턴제 전략 카드 게임**이다.

- 원소 카드를 전장에 배치 → 상대 카드와 전투 → 상대 기지 공격
- 분자 합성, 별(Star) 관리, 에너지 시스템, 핵융합으로 고급 원소 생성
- 라운드 모드(적 기지 파괴 → 다음 라운드), 온라인 매칭, 랭킹

wonso 모드는 이 게임의 **화학 세계관·데이터·시스템**을 Minecraft **야생 서바이벌**에 이식한다.

## 3. 사이트 → Minecraft 야생 이식 매트릭스

### 3.1 직접 이식 (v1 목표)

| 사이트 기능 | Minecraft 구현 | 야생 연계 |
|-------------|----------------|-----------|
| 원소 카드 | `Element Card` 아이템 (118종) | 채굴·정제·발견으로 획득 |
| 분자 도감 | `Chemistry Journal` 책 + Advancement | 합성·발견 시 자동 기록 |
| 화학 합성실 | `Synthesis Lab` 블록 | 작업대 상위 — 분자 조합 |
| 분子 에너지 | `Element Energy` 플레이어 NBT | 분子 분해·에너지 변환 |
| 원소 3모드 UI | Periodic Table Screen (GUI) | 원소/원자/분자 탭 전환 |
| 튜토리얼 | Advancement 트리 (12단계) | 야생 시작 후 점진 해금 |

### 3.2 변형 이식 (v1.1~)

| 사이트 기능 | Minecraft 구현 | 야생 연계 |
|-------------|----------------|-----------|
| 기지 전투 | `Element Shrine` 구조물 방어 | 웨이브 몹 공격 |
| 라운드 모드 | 차원/구조물 웨이브 | 난이도 스케일링 |
| 핵융합 | `Fusion Chamber` 블록 | 희귀 원소 + 에너지 |
| 별 시스템 | `Stellar Core` 아이템·블록 | 심층 야생·네더·엔드 보상 |
| 에너지 스킬 | 소모형 능력 (키바인딩) | 전투·채굴 보조 |
| 연구소 | `Research Table` 블록 | 새 분자·원소 해금 |

### 3.3 서버 전용 (v1.2+)

| 사이트 기능 | Minecraft 구현 |
|-------------|----------------|
| 온라인 매칭 | 전용 **원소 아레나** + 매칭 큐 (플레이어 직접 PvP ❌, 원소령 대전) |
| 랭킹 | 서버 DB / elementwar.xyz API 연동 |
| 채팅 | 바닐라 채팅 + 매칭 로비 |
| 리플레이 | 녹화 모듈 (선택) |

### 3.4 야생 전용 추가 (사이트에 없음 — 모드 차별점)

| 기능 | 설명 |
|------|------|
| **광물→원소 정제** | 철 광석 → Fe 카드, 구리 → Cu |
| **바닐라 화학 반응** | 나트륨+물=폭발, 마그네슘+불 등 |
| **원소 족 시너지** | 같은 족 카드 조합 보너스 |
| **바이옴별 원소 분포** | 사막=나트륨, 바다=염소 등 |
| **주기율표 채굴** | 희귀 `Periodite` 광석 → 랜덤 원소 |

## 5. 사이트 데이터 → 공유 JSON 스키마

elementwar.xyz와 wonso 모드가 **같은 데이터 번들**을 쓰도록 설계:

```text
shared-data/
├── elements.json       # 118원소 (카드 stats 포함)
├── atoms.json          # 원자 구조
├── molecules.json      # 분자 (에너지값, 합성식, 전투 stats)
├── synthesis.json      # 합성 레시피 (원소→분子)
├── fusion.json         # 핵융합 레시피
├── stars.json          # 별 타입·성장·디버프
└── energy-abilities.json
```

**Element Card stats** (사이트에서 암시):

```json
{
  "z": 11,
  "symbol": "Na",
  "nameKo": "나트륨",
  "card": {
    "attack": 3,
    "health": 4,
    "rarity": "common",
    "cost": 2
  }
}
```

**Molecule energy** (사이트 명시값):

| 분자 | 에너지 |
|------|--------|
| H₂O | 3 |
| CO₂ | 2 |
| CH₄ | 6 |
| C₆H₁₂O₆ | 12 |

## 6. elementwar.xyz ↔ wonso 관계

```text
                    ┌─────────────────────┐
                    │  shared-data/       │
                    │  (118원소·분子)     │
                    └──────────┬──────────┘
                               │
           ┌───────────────────┼───────────────────┐
           ▼                   ▼                   ▼
   elementwar.xyz        wonso Fabric Mod     (future)
   (카드 게임 웹)         (야생 서바이벌)       모바일 앱
```

- **웹**: 턴제 카드 게임, 온라인 매칭, 랭킹
- **모드**: 야생 채굴·합성·탐험, PvE 웨이브, **원소 대전 PvP** (포켓몬식)
- **공통**: 원소·분자 데이터, 분자 도감, 합성 규칙, 에너지 값

## 9. elementwar.xyz 연동 (선택)

| 연동 | 방식 | 우선순위 |
|------|------|----------|
| 랭킹 공유 | REST API — 클리어 라운드 제출 | v1.2 |
| 계정 연동 | OAuth / 코드 인증 | v2 |
| 도감 동기화 | 발견 분子 클라우드 저장 | v2 |
| 웹→모드 딥링크 | `wonso://` 커스텀 URL | v2 |

**API 스펙 (제안)**:

```
GET  /api/ranking          → Top 10
POST /api/ranking          → { playerId, rounds, score }
GET  /api/molecules        → 분자 데이터 manifest
GET  /api/player/{id}/dex  → 발견 진행률
```
