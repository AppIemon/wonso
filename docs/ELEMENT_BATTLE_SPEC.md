# wonso — 원소 대전 시스템 (포켓몬식 PvP/PvE)

> **핵심 규칙**: 플레이어는 **직접 싸우지 않음**. 포켓몬처럼 **원소(원소령)** 를 데리고 전투를 지휘한다.
> **레퍼런스**: elementwar.xyz 턴제 카드 전투 + 포켓몬 파티·타입 상성·교체

---

## 1. 한 줄 정의

**원소 대전**은 두 명의 플레이어(또는 플레이어 vs AI)가 각자 **원소 파티**를 꺼내 **원소령(Elemental)** 이 1:1(또는 필드)로 싸우고, 플레이어는 **명령만 내리는 트레이너** 역할을 한다.

```text
[플레이어 A]  ──명령──→  Na 원소령  ⚔️  Cl 원소령  ←──명령──  [플레이어 B]
   (옆에 서기)              (전장에서 실제 전투)              (옆에 서기)
```

- ❌ 플레이어 HP / 플레이어 직접 공격 / 검으로 쓰는 PvP
- ✅ 원소 HP / 원소 스킬 / 교체·도구·족 상성

## 2. 포켓몬 ↔ wonso 대응표

| 포켓몬 | wonso |
|--------|-------|
| 포켓몬 | **원소령 (Elemental)** — 원소 카드가 전장에 소환된 형태 |
| 트레이너 | **플레이어** — 명령 UI만 사용 |
| 파티 (6마리) | **원소 파티** (최대 6슬롯, 인벤 카드에서 등록) |
| 박스 | **원소 보관함** — 118 카드 수집·정리 |
| 타입 (불·물…) | **족/카테고리** (알칼리금속, 할로겐, 전이금속…) |
| 기술 4개 | **원소 스킬** 4슬롯 (족·Z·분자 연계) |
| PP | **에너지 코스트** (턴당 ⚡ 또는 스킬별 cost) |
| 아이템 | **분子 도구** (회복·버프, elementwar 에너지 스킬 대응) |
| 야생 조우 | **원소 조우** — 야생에서 희귀 원소령 출현 (선택) |
| 체육관/리그 | **원소 아레나** — 매칭·랭킹 |
| 교체 | **스위치** — 패배한 원소령 → 다음 원소 등장 |

## 3. 전투 흐름 (턴제)

elementwar.xyz와 동일하게 **턴제**. 실시간 액션은 하지 않음.

### 3.1 한 턴의 순서

```text
1. 턴 시작 (300초 제한 — elementwar 동일, 초과 시 자동 턴 종료)
2. 활성 원소령 상태 표시 (HP, 디버프, 족)
3. 플레이어 명령 선택 (동시 제출 → 동시 공개, 또는 선공·후공)
   ├─ ⚔️ 공격 스킬 (4종 중 1)
   ├─ 🔄 교체 (파티 다른 원소)
   ├─ 🧪 분子 도구 (회복·버프, 턴 소모)
   └─ ⏭ 턴 종료 (패스)
4. 명령 해결 (속도·우선도·족 상성 계산)
5. 원소령 애니메이션 (필드에서 공격·피격)
6. KO 체크 → 교체 강제 or 승패
7. 다음 턴
```

### 3.2 승리 조건 (모드)

| 모드 | 승리 | 패배 |
|------|------|------|
| **PvP 표준** | 상대 파티 전멸 | 내 파티 전멸 |
| **elementwar 기지** (옵션) | 상대 기지 HP 0 | 내 기지 HP 0 |
| **라운드 서바이벌** | N라운드 클리어 | 파티 전멸 |
| **야생 조우** | 야생 원소령 포획/처치 | 파티 전멸 (도주 가능) |

**기본 PvP는 파티 전멸**. elementwar식 **기지 HP**는 랭크·커스텀 룰 옵션.

## 4. 원소령 (Elemental Entity)

### 4.1 소환

| 항목 | 설계 |
|------|------|
| 트리거 | 전투 시작 시 파티 1번 슬롯 자동 출전 |
| 엔티티 | `ElementalEntity` — 클라이언트 전용 시각 + 서버 전투 상태 |
| 외형 | 원소 기호 플로팅 + 족 색 파티클 + Z에 따른 크기 스케일 |
| 위치 | **전투 아레나** 필드 양쪽 (플레이어는 뒤쪽 관전 위치) |
| 플레이어 | 전투 중 **이동·공격 잠금** (관전 모드, 채팅만) |

### 4.2 스탯 (elementwar 카드 stats 연동)

```json
{
  "z": 17,
  "symbol": "Cl",
  "battle": {
    "hp": 45,
    "attack": 12,
    "defense": 8,
    "speed": 14,
    "rarity": "uncommon"
  }
}
```

| 스탯 | 역할 |
|------|------|
| HP | 0 → KO, 교체 필요 |
| Attack | 스킬 데미지 기본값 |
| Defense | 받는 데미지 감소 |
| Speed | 같은 턴 명령 시 선공 결정 |
| Rarity | 희귀도·랭크 매칭 가중치 |

### 4.3 스킬 4슬롯 (예시: Cl 염소)

| 슬롯 | 스킬명 | 타입 | 코스트 | 효과 |
|------|--------|------|--------|------|
| 1 | 염소 가스 | 할로겐 | 0 | 기본 공격 |
| 2 | 산화 공격 | 할로겐 | 8⚡ | 방어 무시 소량 |
| 3 | 독성 잔류 | 할로겐 | 12⚡ | 3턴 독 DOT |
| 4 | 족 시너지 | — | 15⚡ | 할로겐 아군 있을 때 데미지 2배 |

스킬은 **족·원자번호·합성 분子**로 해금 (교육 연계: Cl 학습 → 독 스킬 해금).

## 5. 족(타입) 상성 — 화학 기반

포켓몬 타입 상성을 **주기율표 족·성질**로 대체.

### 5.1 상성 매트릭스 (v1 간소화)

| 공격 족 | 강함 (↑데미지) | 약함 (↓데미지) |
|---------|----------------|----------------|
| 알칼리금속 (1족) | 할로겐 | 전이금속 |
| 할로겐 (17족) | 알칼리금속, 알칼리토금속 | 귀금속 |
| 전이금속 | 알칼리금속 | 할로겐 |
| 귀금속 | 할로겐 | 알칼리금속 |
| 비활성 기체 (18족) | — | 모든 공격 (방어↑) |
| 비금속 | 금속 | 할로겐 |

**STAB** (Same-Type Attack Bonus): 자기 족 스킬 → 데미지 ×1.2

### 5.2 분子 도구 타입

| 분子 | 도구 효과 |
|------|-----------|
| H₂O | HP 30% 회복 |
| NaCl | 방어 +1단계 |
| H₂O₂ | 공격 +1단계 |
| C₆H₁₂O₆ | HP 50% 회복 (턴 2 소모) |

## 6. 파티 & 보관 (야생 연계)

### 6.1 원소 파티

| 항목 | 규칙 |
|------|------|
| 슬롯 | 최대 **6** (포켓몬 동일) |
| 등록 | Chemistry Journal → 파티 편성 GUI |
| 소스 | 야생에서 모은 **원소 카드** |
| 중복 | 같은 Z 카드 여러 장 보유 가능, 파티엔 1종 1마리 |
| 레벨 | v1: 카드 고정 stats / v1.2: **원소 경험치** (전투로 성장) |

### 6.2 원소 보관함

- 118종 수집 진행률 (도감 연동)
- 정렬: Z, 족, 희귀도, HP, 미사용

### 6.3 야생에서 파티로

```text
광물 정제 / 주기율광석 / 조우
        ↓
  원소 카드 획득
        ↓
  보관함 or 파티 등록
        ↓
  PvP / PvE / 라운드에 사용
```

## 7. PvP — 온라인 원소 대전

elementwar.xyz **온라인 매칭**을 모드로 이식.

### 7.1 매칭 플로우

```text
[야생 월드]                    [원소 아레나 차원]
     │                              │
  Journal → "온라인 대전"          │
     │                              │
  매칭 큐 등록 ──────────────────→  매칭 완료
     │                              │
  (야생에서 대기, 이동 잠금 없음)   │  양쪽 파티 스냅샷 전송
     │                              │
  매칭 성공 → 아레나 텔레포트 ───→  전투 필드 입장
     │                              │
  관전 위치 고정                   │  원소령 소환
     │                              │
  Battle UI (명령)                 │  턴제 전투
     │                              │
  승/패 → 결과·랭킹 ─────────────→  야생 or 로비 복귀
```

### 7.2 아레나 규칙

| 항목 | 규칙 |
|------|------|
| 차원 | `wonso:arena` — 전용 차원 or 인스턴스 구역 |
| 플레이어 수 | 2 (1v1), v2: 2v2 |
| 직접 전투 | **금지** — friendly fire off, 플레이어 데미지 0 |
| 관전 | 전투 구역 밖 이동 불가, 카메라 원소령 추적 옵션 |
| 도주 | 3턴 이내 도주 = 패배 처리 (랭크) |
| 재접속 | 60초 내 복귀, 없으면 패배 |

### 7.3 랭킹 (elementwar 연동)

| 기록 | 설명 |
|------|------|
| 승/패 | ELO or 점수 |
| 클리어 라운드 | 라운드 모드 (elementwar 동일) |
| 사용 원소 | 통계 (선호 족) |

`elementwar.xyz` API 제출 (v1.2): `{ playerId, wins, rounds, score }`

## 8. PvE — 같은 시스템

| 상대 | 설명 |
|------|------|
| **AI 트레이너** | elementwar 컴퓨터 상대 — AI 생각 과정 UI |
| **야생 원소령** | 필드 조우 → 전투 or 포획 |
| **Elemental 몹** | 족별 특수 몹 — 처치 시 카드 드롭 |
| **라운드 웨이브** | Element Shrine — 연속 AI 파티 |
| **보스** | 희귀 원소 (U, Og 합성 전 프록시) |

PvE도 **플레이어 직접 공격 없음** — 명령 UI만.

### 9.1 화면 레이아웃

│                          │  [상대 파티 6슬롯 미니]        │
│   3D 필드 (원소령 실제)   │  Cl ████████░░ HP 32/45      │
│                          │                              │

## 10. 멀티플레이어 기술 (Fabric)

## 11. 야생과 전투의 루프

```text
        ┌──────────────┐
        │  야생 탐험    │
        │  광물·정제    │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │ 원소 카드     │
        │ 수집·파티편성 │
        └──────┬───────┘
               ↓
    ┌──────────┴──────────┐
    ↓                     ↓
┌─────────┐         ┌─────────┐
│ PvE     │         │ PvP     │
│ AI·조우 │         │ 매칭    │
│ 라운드  │         │ 랭킹    │
└────┬────┘         └────┬────┘
     ↓                   ↓
┌──────────────┐   ┌──────────────┐
│ 보상·카드    │   │ ELO·랭킹     │
│ 분子·에너지  │   │ elementwar   │
└──────┬───────┘   └──────────────┘
       ↓
┌──────────────┐
│ 합성·도감    │
│ 3모드 학습   │
└──────────────┘
```

**야생은 덱(파티) 빌딩**, **전투는 덱 테스트** — 포켓몬 구조와 동일.

## 13. 명시적 금지 사항

| 금지 | 이유 |
|------|------|
| 플레이어가 검·활로 상대 플레이어 공격 | 포켓몬식 원소 대전 컨셉 |
| 전투 중 플레이어 본체가 스킬 시전 | 원소령이 시전 |
| 야생 월드에서 파티 없이 PvP 강제 | 덱 없으면 매칭 불가 |
| 전투 없이 카드만으로 랭크 | 최소 1전 필요 |
