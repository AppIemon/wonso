# wonso — 바닐라 거친 정제 (Vanilla Crude Refining)

> **상위 설계**: [REAL_WORLD_EXTRACTION.md](./REAL_WORLD_EXTRACTION.md) — **현실 화학·산업 공정**이 먼저, 이 문서는 그걸 마크에서 **지지리게** 구현하는 방법.
> **핵심**: 모래·석영·철·금 등 바닐라를 **실제 광물·화합물(SiO₂, Fe₂O₃, NaCl…)** 로 해석한 뒤, **정광·전기분해·환원·증발** 등 **실제 공정 이름**으로 우려낸다.

---

## 0. 현실 반영과 게임화의 관계

| 층 | 문서 | 내용 |
|----|------|------|
| 화학 진실 | REAL_WORLD_EXTRACTION | SiO₂+C→Si, NaCl 전기분해… |
| 게임 구현 | 이 문서 | 같은 반응 + 대량 소모 + 슬러지 + RNG |

**원소 카드를 바로 주지 않음** — 중간물은 `silicon_dioxide`, `sodium_chloride` 등 **실제 화합물 이름**.

---

## 1. 설계 원칙

| 원칙 | 설명 |
|------|------|
| **현실 1순위** | 공정·화합물·풍부도는 REAL_WORLD_EXTRACTION 준수 |
| **바닐라 1순위** | 입력의 90%+는 마크 기본 블록·아이템 |
| **화합물 우선** | 모래 = Si ❌ → **SiO₂** → 환원 후 Si |
| **실제 공정명** | 전기분해, 정광, 고온 환원, 증발, 침출, 증류 |
| **지지리게** | 현실도 Al·Na는 에너지 지옥 → 게임도 ⚡·시간 대량 |
| **지저분한 산물** | 슬래그·적색 슬러지·CO₂ — 산업 부산물 |
| **새 광물은 보조** | 주기율광석 = 희귀 원소만 |

```text
[64 모래]  (= SiO₂ 입자, 현실: 석영 사막)
    → 분쇄 → silicon_dioxide_powder
    → 고온 환원 (Reduction Furnace + 목탄 환원제, 현실: SiO₂+2C→Si+2CO)
    → metallurgical_silicon + slag + CO_offgas
    → 순화 → Si 원소 카드
```

## 2. 정제 파이프라인 (4단)

### Stage 0 — 바닐라 수집 (그라인딩의 원천)

플레이어가 **평소 야생처럼** 캐고 모은 것들을 쌓아둔다.

### Stage 1 — 분쇄 `Crushing`

| 도구/블록 | 입력 | 출력 |
|-----------|------|------|
| 맷돌 + 아이템 (인벤) | 모래 16 | `silica_grit`×4 + `sand_dust`×8 |
| 맷돌 | 조약돌 16 | `stone_powder`×6 + `metal_trace`×1(랜덤) |
| 맷돌 | 석영 8 | `quartz_dust`×4 + `silica_grit`×2 |
| 맷돌 | 철 광석 8 | `iron_ore_powder`×4 + `rock_slag`×2 |
| 맷돌 | 네더 석영 8 | `nether_quartz_dust`×4 |

- **지지리 포인트**: 맷돌 우클릭 연타 or 분쇄기 블록에 **시간** 투입
- 분쇄기 (`Crusher`) — v1.0: 돌+철로 조합, 틱 소모, 소리 지지직

### Stage 2 — 용해 / 반응 `Dissolving`

**정제 반응통** (`Reaction Vat`) — 화로 다음 티어, 물·용액 필요

| 입력 | 추가 | 출력 |
|------|------|------|
| `silica_grit`×4 + 물 양동이 | 석탄 2 | `murky_silicon_slurry`×2 + `waste_sludge`×1 |
| `iron_ore_powder`×4 + 물 | 석탄 4 | `iron_slurry`×2 + `sulfur_trace`×1(랜덤) |
| 목탄 16 | — | `carbon_residue`×4 + `ash`×8 |
| 물 양동이×4 | 레드스톤 8 (촉매) | `electrolyzed_hydrogen`×1 + `oxygen_bubble`×1 (느림) |

- **지지리 포인트**: 물 양동이 **소모**, 연료 **많이**, 출력은 **슬러지** 이름

### Stage 3 — 거친 정제 `Crude Refining`

**원소 정제기** (`Element Refinery`) — 모드 핵심 블록

| 슬롯 | 내용 |
|------|------|
| 입력 1~3 | 슬러지·분말·바닐라 아이템 |
| 촉매 | 레드스톤 / 구리 / `Refining Catalyst` |
| 연료 | 석탄·목탄 (화로 2~4배 소모) |
| 출력 | `impure_element_{symbol}` (불순 원소 잔여물) |
| 부산물 | `slag`, `toxic_waste`, `wrong_element_chip` |

**처리 시간**: 200~600틱 (10~30초), 화로보다 느림

**성공률** (초반):

| 티어 | 기본 성공률 | 실패 시 |
|------|-------------|---------|
| Tier 1 (C, Fe, Si, O…) | 65% | 입력 절반 소멸, 슬래그만 |
| Tier 2 (Cu, Al, Na…) | 45% | + 독 슬러지 |
| Tier 3 (희귀) | 20% | + 폭발 소량 (Na 등) |

연구·촉매·Advancement로 성공률 상승 (최대 95%).

### Stage 4 — 순화 `Purification`

불순 잔여물은 **아직 카드 아님** — 이름만 `불순 규소 잔여물`.

| 방법 | 입력 | 출력 |
|------|------|------|
| 2차 정제 | `impure_Si`×3 + 촉매 | `pure_Si`×1 (50% 확률) |
| 합성실 순화 | `impure_Si`×2 + 에너지 5 | **Si 원소 카드**×1 |
| 연구 해금 후 | `impure_Si`×1 + H₂O | 카드×1 (효율 업) |

**지지리 정점**: 모래 64장 → 카드 1장까지 **4단계 + RNG + 연료 수십 개**

## 4. 중간 아이템 (지저분한 인벤 토이)

플레이어 인벤이 **화학 실험실 지저분한 책상**처럼 됨.

| 아이템 | 설명 | 처리 |
|--------|------|------|
| `slag` (슬래그) | 정제 부산물 | 쌓기/버리기/슬래그 블록 제작 |
| `waste_sludge` | 폐 슬러지 | 투척 or 폐기 블록 |
| `wrong_element_chip` | 랜덤 Z trace | 10개 모으면 랜덤 원소 1 |
| `sand_dust` | 모래 먼지 | 다시 분쇄 or 버림 |
| `metal_trace` | 미량 금속 | 8개 → 1 슬러지 |
| `toxic_waste` | 독 폐기물 | Na/S 반응 시 생성, 닿으면 약독 |
| `murky_*_slurry` | 탁한 용액 | 정제기 입력 |
| `impure_*` | 불순 원소 | 순화 대기 |
| `ash` | 재 | C trace 추출 가능 (소량) |

**인벤 관리도 게임플레이**: 상자·드럼·폐기통 블록 (`Waste Bin`) 권장.

## 5. 블록·도구 (정제 전용)

| 블록/도구 | 티어 | 역할 |
|-----------|------|------|
| 맷돌 (바닐라) | 0 | 수동 분쇄 |
| `Crusher` | 1 | 자동 분쇄 |
| `Reaction Vat` | 1 | 침출·용해·산 처리 |
| `Evaporation Pan` | 1 | **증발** — 해수→식염 (현실) |
| `Element Refinery` | 2 | 정제·순화 (핵심) |
| `Electrolyzer` | 2 | **전기분해** — NaCl, H₂O, Al₂O₃ |
| `Distiller` | 2 | **증류·공기 분리** — N₂, O₂, Ar |
| `Reduction Furnace` | 2 | **고온 환원** — SiO₂→Si, Fe₂O₃→Fe |
| `Synthesis Lab` | 3 | 순화 + 분子 합성 |
| `Waste Bin` | 1 | 부산물 안전 폐기 |
| `Slag Bin` | 1 | 슬래그 압축 저장 |

조합은 **바닐라 재료만**으로 1티어 가능:

```text
Reaction Vat = 화로 + 양동이 + 조약돌
Element Refinery = 화로 + 철 블록 + 레드스톤 + 석영
```

## 6. 바이옴·야생 루트 (바닐라 블록 조합)

| 바이옴 | 바닐라 활용 | 원소 힌트 |
|--------|-------------|-----------|
| 사막 | 모래 대량 + 사막 사원 석재 | Si, **Na** (켈프+모래+물 브라인) |
| 바다 | 켈프, 모래, 물 | **Cl**, I, H, O |
| 늪 | 점토, 슬라임, 물 | S, N, C |
| 산 / 고원 | 돌, 자갈, 석영 | Si, Al, Ca |
| 네더 | 영혼 모래, 석영, 금 광석 | S, Au, Si |
| 엔드 | 석영, 돌, 드래곤 관련 | 희귀 trace |

**나트륨/염소 예시 (지지리)**:

```text
켈프 32 + 모래 16 + 물 4 + Reaction Vat
  → `salt_brine`×2 + sludge
  → Refinery + 석탄 8
  → `impure_Cl`×1 (60%) + `impure_Na`×1 (40%) — 동시에 안 나옴
  → 각각 순화 → Cl 카드 / Na 카드
```

## 13. 플레이어 체감 목표

> "철 캐고 모래 캐던 게 **원소 파티**를 만드는 그라인드였구나."
> "슬래그가 왜 이렇게 많아…" → **지지리게** 원소 1장의 가치 상승 → PvP 덱 자랑

바닐라 야생 **그 자체**가 원소 수집의 90% — 새 광물은 **스위트**만.
